DynastyWire - Road to Glory
===========================

No installer. Put DynastyWire.exe wherever you like and run it.

FIRST RUN
  1. Point it at your CFB 27 save file (dynasty OR Road to Glory - it works out
     which on its own).
  2. Paste your Anthropic API key. It stays on your machine; nothing is uploaded.

UPDATES
  The app replaces itself. When a new version is out you get a small prompt in
  the corner you can always decline, and it tells you when the update landed.
  Keep the .exe somewhere you have write access (not Program Files).

ROAD TO GLORY
  Open an RTG save and the app becomes RoadWire - your own front page, feed,
  podium, phone, gameplan, position room and recruiting board.

THE FORUM
  Browse other people's dynasties from inside the app. Publishing yours is
  opt-in, in Settings > Sharing, and it shows you exactly what would travel
  before anything is sent.

Windows may warn about an unrecognised app; the binary is signed for the
updater, not with a paid code-signing certificate. Choose More info -> Run anyway.
